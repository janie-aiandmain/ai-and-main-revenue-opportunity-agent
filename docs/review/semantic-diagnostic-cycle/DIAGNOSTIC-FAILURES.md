## Contract limitations are still a failing gate

EN11 and EN12 each require two independent findings. The original single-summary contract cannot represent both, evidence isolation, stable finding IDs or approval-bound action versions. Their classification/review checks can pass while independent coverage remains unmeasured. The default diagnostic therefore still exits **1**, exposes both cases as `contractLimitedCases`, and sets `releaseEligible: false`. No expectation was changed or deleted.

The existing operator finding engine already supports independent findings; this diagnostic is not being expanded into that engine or a CRM. Migration or retirement of the legacy runtime fallback needs a separate decision.
